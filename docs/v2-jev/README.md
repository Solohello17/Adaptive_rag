# v2.0 docs: Jev decision layer

v2.0 adds Jev, a "System One" judgment model by [TypeSafe AI](https://docs.typesafe.ai), as a swappable decision layer for routing, grading, and answer verification. The LLM keeps doing all the writing. The graph architecture follows [Dhruv Singhal's Adaptive-Rag](https://github.com/dhruvsinghal09/Adaptive-Rag).
